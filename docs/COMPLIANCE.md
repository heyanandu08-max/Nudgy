# Compliance checklist

What Nudgy does for each common legal requirement, and what is still yours to do before
launch. A refund policy is out of scope by decision. None of this replaces a lawyer: have
one review `backend/legal/` before launch.

| # | Requirement | Where it lives | Status |
| --- | --- | --- | --- |
| 1 | Privacy policy | `backend/legal/privacy.md`, served at `/privacy`, linked from sign-in, Settings → About and every page footer | Done; lawyer review |
| 2 | Terms of service | `backend/legal/terms.md` at `/terms`; agreed to at sign-in | Done; lawyer review |
| 4 | Cookie policy | `backend/legal/cookies.md` at `/cookies`: the app sets none; web pages none unless analytics is accepted | Done |
| 5 | Cookie consent banner | Server pages show it only when `NUDGY_ANALYTICS_SRC` is set; nothing optional loads before "Accept"; "Decline" is equally easy | Done |
| 6 | Form consents | Sign-in has an unticked box (13+ and Terms/Privacy); the server refuses sign-in without it and records version + time | Done |
| 7 | Collect only what's needed | Server keeps email, consent, plan, usage counts. Google/Apple asked for email only (no name or profile). Screenshots and audio never stored | Done |
| 8 | Audit third-party services | Listed with what each receives in the Privacy Policy ("Services we use"). No analytics, ads or crash SDKs in the app | Done; re-check when adding a service |
| 9 | No dark patterns | Consent box unticked; shortcut tips off by default; upgrade screen has "Not now" and closes with Esc; cancelling is one link to PayPal; no fake timers or pre-selected upsells | Done |
| 10 | No hidden fees | Prices shown before subscribing; note that prices are USD and PayPal shows any tax before confirming; Terms state auto-renewal and 30 days' notice of price changes | Done |
| 11 | No fake reviews | No reviews or ratings anywhere in the app or site; the marketing plan forbids fake reviews and bought upvotes | Done |
| 12 | No unsupported claims | Copy reviewed: "exact button" softened to "the button"; privacy wording made precise (walkthrough pictures are stored locally, question screenshots are not); no claims about vendors' training policies | Done |
| 13 | Alt text | Logo has alt text; walkthrough screenshots describe their step; decorative icons are `aria-hidden` | Done |
| 14 | Colour contrast | Grey text darkened to 4.9:1, orange text uses a darker shade (5.2:1), green 4.6:1 (WCAG AA); orange stays for dots and fills | Done |
| 15 | Keyboard navigation | Visible focus everywhere (including the Home ask box); tabs move with arrow keys; Esc closes the upgrade screen | Done |
| 16 | Business details | `NUDGY_COMPANY_NAME`, `_ADDRESS`, `_COUNTRY`, `NUDGY_CONTACT_EMAIL`: shown on legal pages, page footers, Settings → About, invite emails. Required in production | **Fill in `.env`** |
| 17 | Age consent | 13+ confirmed at sign-in (16 where local law requires: covered in Terms/Privacy) | Done |
| 18 | Unsubscribe link | Team invitations carry a one-click unsubscribe link and `List-Unsubscribe` headers; unsubscribed addresses get no more invites. Sign-in links are only sent on request | Done |
| 19 | Licenses for fonts and images | Fonts are OFL-1.1; logo and icons are our own; every package and its license at `/licenses`, generated by `scripts/licenses.py`, which fails on GPL/AGPL | Done; re-run after dependency changes |
| 20 | Data deletion request | In-app "Delete my account"; `/delete-account` explains it and gives an email route for people without the app | Done |

## Before launch

- [ ] Fill in the business details in `.env` (the server won't start in production without them).
- [ ] Have a lawyer review `backend/legal/privacy.md`, `terms.md` and `cookies.md`; bump
      `TERMS_VERSION` in `backend/app/services/legal.py` after any substantive change.
- [ ] Make sure the contact email is monitored: deletion and privacy requests arrive there.
- [ ] If you add site analytics, set `NUDGY_ANALYTICS_SRC` and update the Cookie Policy table.
- [ ] Run `python3 scripts/licenses.py` after changing dependencies.
